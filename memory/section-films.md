## How to pull a trigger

1. Ewan names the **next id** (table below).
2. Draw in house: HTML/CSS in `Site/public/brief/social-loop/{id}.html`, 16:9 and 9:16, same clunk language as the host loop (caret, grey bar, enter, Push, blip — only if the story needs them).
3. Review on the house (`dln.local` / `192.168.0.223`), iterate like Sandbox Live.
4. If it belongs on the campus room, swap the room widget to that loop. If it is ads-only, leave the room as it is.
5. Zip + review page when it is happy. Then the next id. Never two at once.

## What a loop is allowed to be

- Line drawing. Few moving parts. One idea.
- No Follicle Files / ATTW / Applearn / PFP stills in the picture. Portfolio lives in Portfolio.
- No generated Swarm / Swimming Through Leaves / DLN marks. Pull from `Site/public/plots/` and `Site/public/brand/`.
- No GBP, no Cursor, no desk-as-product, no “deck”.
- UK English if any type is in frame (prefer none).

## What this is not

- Not the three-door *talk* films (entrepreneurs / new / refresh). Those stay in `memory/social-video-blueprint.md`.
- Not a batch generate.
- Not a public header door.
- Not engagement copy on the homepage.
