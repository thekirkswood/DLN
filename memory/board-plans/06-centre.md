# Centre — the thing itself

Own: `/board/plot` rewrite as showcase. Do **not** hang BrandBoard’s heavy compile on the walking path. Full book stays a deeper click or a named “open the book” that isolates the cost. Bits stay at `/board/plot/{bit}`.

## Job

The plot. Their work. A short tailored view from the **whole book**. Click through for the full cell. Assets and generated plates sit here.

If mission is held, it appears. If two seats are named, they appear. If a host exists, it appears. If nothing is held, the room says this plot has not written the thing itself yet — and still looks like the centre of a table, not an empty CMS.

## What is wrong now

`/board/plot` is the communal BrandBoard. It can freeze the desk. Walking the MAP should never open that compile. The centre on the overview already links here; it must be light.

## Unique interior

A **showcase**, not a spreadsheet of bits.

1. Plot name, status, host link.
2. One hero: mission line if held, else purpose, else identity statement, else empty stand.
3. A ring or strip of what the book already holds — identity snippets, a landscape neighbour, two seats, the process stage if named — each a door.
4. A still well: shared Assets ticked for this plot (socket until the hook). Generated plates later sit in the same well, labelled as generated.
5. “Open a cell” does not dump twenty identical forms; it uses the unique interiors from 03–05.
6. Heavy BrandBoard only behind an explicit control, or retire it from this route.

## Interconnect

This is the master entity. Every other plan is done only if this view would change. Overview centre plate is a miniature of this.

## Multi-format

This is where images integrate with text. Stills from brand, from landscape, from sittings. Morph: as cells fill, the showcase composition changes (not a random shuffle — a stable layout with slots that light).

## Look

Centre of the MAP language: larger, stiller. Not a dashboard. Chamfered well. Aktiv Black for the hero line if it is a mission.

## Done when

A plot with mission + two seats + a host shows those three without opening the heavy book. An empty plot is still the thing itself, vacant. Clicking a snippet enters the unique cell.

Binder3 also names centre asset-system fragments (Name, Strapline, Device, Colour, Type, Tone, Motion, Sound, Asset System, rules, commentary, examples). Those are **not** extra left-column bits. They belong in this showcase as slots that light when Assets exist — later, not as a second identity list.

## Do not

Compile every bit into one page on first paint. Fake a generated hero. Call this “BrandBoard.” Delete BrandBoard’s funnel/mailbox — move it off the walking path, do not destroy the book.
