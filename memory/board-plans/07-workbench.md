# Workbench — coal face

Own: `/board/workbench/{tools,ideas,board,host}` unique interiors. Faculty 04.

## Job

Taking great ideas through the process. Artwork, production, code, printers, servers. Delivery where execution matches strategy.

The **board** on this avenue is this space: zoom a topic, watch the effect on *their* plot. The **host** is the live plot they sit with while it grows. Sandbox and live are two rooms. Trying a thing must not overwrite the public site.

## Four rooms

**Tools.** What is being made, in which file. Printers, servers, hands. A list of actual tools in use (named), not “Adobe.” Door to process stage 6.

**Ideas through.** Taking a great idea through the process, not around it. Reads big-idea and mission. Shows which process stage the idea is in. If they want to skip to implementation, the room should show the skipped checkpoints as holes.

**The board.** Zoom/effect on their plot. This is not a second overview — it is a working window: pick a cell, see neighbours light, see the centre snippet. Effect = the plot file changing. Until generate exists, the effect is hold/read only.

**Host.** Live site and a constant sandbox. One package. Price follows traffic (tester may print £; live public does not until ship). Named URL. Status. Door to location bit and process stage 7. Sandbox vs live as two plates, not a toggle that overwrites.

## Pad

Note 3 (the board) and note 4 (the live host) land here.

## Interconnect

Host empty → Implementation cannot honestly complete. Tools empty → Build is description. Ideas-through without a big-idea still allows a wide pass (process 4).

## Multi-format

Tools and host want stills (a pack, a screen). Generate does not run production.

## Look

More workshop, still Paper/Ink. Two plates for sandbox/live. No neon IDE theme.

## Done when

You can name what is being made, whether it is sandbox or live, and zoom a topic on their plot from this avenue. Host is a place, not a URL field in a sheet.

## Do not

Overwrite live from sandbox. Put `/admin` back. Price on the public live host until a numbered ship (tester `:3010` may show Host £).
