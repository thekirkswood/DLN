# Identity systems toolkits (faculty 06)

Own: `/board/identity/{principles,ethics,toolkit,systems}`. Different from left-column bits (`03-identity-bits.md`).

## Job

Tools to print or buy — for humans only. Understanding, breaking, and fixing identity systems. A flyer cannot invent a second identity. Procurement and design are not two brands.

The left column is **theirs to fill**. This avenue is **the system that holds those fills** as the work grows.

## Four rooms

**Principles.** What the system will not break. One rule you could print. Reads standards/ethics/philosophy bits as material, not as this room’s contents.

**Ethics (faculty).** Protocols that hold as the work grows. Different from the plot’s ethics bit (what *they* will not do for a win). This is our protocol for the system.

**Toolkit.** Tools to print or buy. Named artefacts: a letterhead, a pack, a screen, a rule sheet. For humans only — not a prompt pack. Door to brand-type (what the toolkit is allowed to be).

**Systems.** Understand / break / fix. Where the identity has already split, in one concrete example (a flyer vs a site). What fixing it would change on the table.

## Interconnect

If bits say rebel and the toolkit is a house, Systems must show the split. Brand-type constrains Toolkit.

## Look

Rule plates. Not the mission stand-in. More protocol, like process, because this is ours.

## Done when

You can name the rule that survives a rush job, point at a split (flyer vs site), and see their filled bits as the material the system has to hold.

## Do not

Merge with `/board/plot/ethics`. Sell a downloadable “AI toolkit.” Invent a mark.
